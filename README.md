# Silverlink

Build a mobile-first web app for seniors in Singapore to find community, connection, and support services nearby.

Design vibe:

Calm, warm, and reassuring — not clinical

High contrast, large readable text (minimum 18px body, 28px headings)

Soft rounded corners, generous spacing between elements

Big tappable targets (minimum 60px tall)

Neutral background (off-white), one accent color for primary actions

Page 1 — Language Selection:
A single centered screen with the heading "Choose your language" and four large buttons below it:

English

中文 (Chinese)

Melayu (Malay)

தமிழ் (Tamil)

When a language is tapped, store the selection and move to Page 2. The selected language should be visibly highlighted before advancing.

Page 2 — What do you need?
Heading: "How can we help you today?" with three large cards below, each with an icon and a short label:

👥 Community — "Meet people and join activities"

🤝 Connection — "Find someone to talk to"

🏠 Support — "Get help with daily needs"

Each card is fully tappable and should feel inviting. For now, tapping a card can just show a placeholder screen with the card name — we'll build the next pages later.

Do not add login, database, or any backend logic yet. Keep it simple and clean.

Don't change anything else after this.
