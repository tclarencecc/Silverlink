# Connection support listings

## Build
- Store the verified services from SAGE Counselling Centre and Singapore Social Support in a local JSON catalogue.
- Show those services when “Someone to talk to” is selected, using the same readable card list pattern as Sports, Hobbies, and Music.
- Include service name, provider, translated description, eligibility, hours, phone/email actions where available, and a source link.
- Keep “Find a group to join” unchanged because both supplied pages contain helplines rather than joinable groups.

## Languages
- Add English, Chinese, Malay, and Tamil text for descriptions, hours, eligibility, counts, source labels, and action buttons.
- Preserve official organisation and service names as published.

## Verification
- Check the flow and list in a phone-sized browser in all four languages.
- Confirm calls, email links, external details links, and the app build work.
